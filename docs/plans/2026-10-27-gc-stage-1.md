# Garbage collection, stage 1: the judge - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tree goes when it holds nothing that exists nowhere else, and its branch is judged on its own: tier 1 of
the design (removed by the collector itself, one line in the report), wired into `retire` and `flotilla fleet clean`,
and run by the orchestrator as the last step of `fleet down`.

**Architecture:** A new package `flotilla/gc/` holds the judge: refs and landing (`refs.py`), parking
(`park.py`), ignored files by rule 1 (`ignored.py`), branch verdicts (`branches.py`), tree verdicts (`trees.py`),
removal under the ledger's lock (`remove.py`) and one pass with its grouped report (`sweep.py`). `fleet/cleanup.py`
keeps its public names (`judge`, `remove`, `sweep`, `sweep_branch`, `Verdict`) as a thin facade over it, so
`retire.py` and `fleet/commands.py` change little. Everything the design puts in tier 2 or 3 stays exactly what
today's sweep does with a doubt - kept, named - until stage 2 brings the archive and the person's recorded answers.

**Tech Stack:** Python 3.11+ stdlib, git >= 2.38 through `subprocess`, pytest through
`uv run --with pytest python -m pytest -p no:cacheprovider -q tests/`.

**Spec:** `docs/specs/2026-10-21-gc-design.md` (approved by the person 2026-10-27). Sections implemented here: 5.1 to
5.5, 6 rule 1 (plus the `settings.local.json` twin of rule 5), 9's report shape for tier 1, 10. Not here: stage 2
(sections 6 rules 2-5, 7, 9's questions, answers and guard) and stage 3 (sections 4 e-k, 8, 7's lifetime).

## Global Constraints

- The person's rule: nothing that cannot come back is removed without the person's recorded word; in this stage that
  means anything not tier 1 is kept and named, never removed.
- Holders are every ref in every namespace (`refs/heads`, `refs/remotes`, `refs/tags`, `refs/attic/*`,
  `refs/flotilla/parked/*`, any other), minus the refs this same pass deletes; other trees' HEADs are never holders.
- Branch decisions are made first; trees are judged against the refs that survive; the holder is re-read at removal.
- Landed = every commit on origin's trunk as origin answers now, or a squash whose exact tip the ledger shipped; in
  local flow (`[flow] mode = "local"`, the default) the local trunk; a declared extra trunk at its local tip.
- Branches on origin are never deleted. A declared trunk is never judged. A person's own tree or branch is never
  judged (only what `_made_by_flotilla` names, plus the sender's branches the ledger proves).
- Parked refs: `refs/flotilla/parked/<tree or branch>/<sha>`, name made safe for `git check-ref-format`; they never
  expire and nothing here deletes them.
- `git worktree remove` without `--force`, always; a branch is deleted only while it points at the judged commit.
- Public tree: no personal names, home paths or other projects in code, tests or docs (commit 3f31e41's rule).
- Lines at most 120 characters; no Cyrillic in the tree (`tools/check_no_cyrillic.py`).
- Tests that make merge commits pass `*IDENTITY` from `tests/ledgerkit.py` (CI runners have no git identity).

## Review Focus

1. **A branch checked out in a tree that stays is deleted anyway** - `git update-ref -d` does not refuse it and
   leaves the tree on an unborn branch. Expect: kept, named. Test in Task 5.
2. **A worktree whose directory is gone** (`git worktree list` marks it `prunable`). Expect: named "missing" in the
   report, not pruned, no crash. Test in Task 7.
3. **A branch or tree name that is not a legal ref component** (`a..b`, a space, a trailing `.lock`, `@{`). Expect:
   the parked ref is still created under a safe name and found again. Test in Task 2.
4. **A spawn cutting or locking a tree while the pass runs.** Expect: the removal aborts on the worktree lock (git
   exit 128), the tree stays, the line says a session holds it. Test in Task 6.
5. **Thousands of refs** (twosuns: 558 local, 344 remote branches). Expect: holders go to git on stdin, never as
   argv. Test in Task 1.
