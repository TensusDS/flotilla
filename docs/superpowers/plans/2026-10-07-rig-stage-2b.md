# Rig stage 2b (0.10.0) - `rig run` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A seat runs one command on a rented machine - `flotilla rig run [--put P]... [--get P]... [--env N=V]... --
COMMAND` - and gets its output, its exit code and its artifacts back, inside the person's open session, with the
machine's lease and heartbeat renewed by the run itself.

**Architecture:** Three new modules under `flotilla/rig/`:
- `remote.py` - the ssh command line and the constant shell scripts the machine runs; what varies travels as quoted
  positional arguments, never spliced into a script.
- `transfer.py` - the gate on the tree (tracked changes), `--put` packing with its refusals, and the safe unpacking
  of `--get`.
- `run.py` - the run itself: queue, machine, tree, setup cache, the command under the lane's runner, renewal,
  `lost`, artifacts, the record.

The journal gains run records (`j1`, `j2`, ...). Each run executes in its own copy of the revision on the machine
(`/work/<project>/runs/<run id>`), so a `--put` or an artifact never reaches another run. Tests never call real ssh:
a stand-in `ssh` program runs the remote line in a local bash inside its own session, so the real quoting is under
test.

**Tech Stack:** Python 3.11+ stdlib only (`subprocess`, `tarfile`, `shlex`, `threading`, `hashlib`), bash on the
machine, OpenSSH client on the field machine, pytest.

**Spec:** `docs/specs/2026-10-06-rig-design.md` - section 7 (a run) is binding; sections 4-6 (who may do what,
safeguards, secrets) and section 12 "Live check 1" (measured facts) constrain it.

## Global Constraints

- Python stdlib only; `requires-python >= 3.11`; Linux and macOS field machines.
- English only in code, docs and messages (`tools/check_no_cyrillic.py`).
- Lines at most 120 characters.
- No real network, crontab, ssh or ssh-keygen in tests (conftest fixtures; the ssh stand-in below).
- `pyproject.toml` already sets `-q`: run pytest without another `-q` and read the summary line.
- Spending only inside a session the person opened; a run never opens one (spec section 4).
- No variable crosses from the field machine except those named with `--env`; names containing `KEY`, `TOKEN`,
  `SECRET` or `PASSWORD` are refused (spec section 7).
- `--put` refuses `.env*`, `*.pem`, `id_*`, `credentials*`, anything outside the tree, and symlinks (spec section 7).
- `--get` refuses absolute paths, paths leaving the tree, symlinks; total capped at 500 MB by default; lands in a
  temporary directory first (spec section 7).
- A broken connection is its own outcome: ssh 255 -> `rig run` exits 75, verdict `lost` (spec section 7).
- The ceiling on a run's time is the lane's ceiling for the project (`flotilla.lane.commands.ceiling_for`).
- The run renews its lease and the heartbeat every 5 minutes. The heartbeat is the file `/root/flotilla-heartbeat`
  touched over ssh: an ssh login shell does not carry `CONTAINER_ID`/`CONTAINER_API_KEY` (live check 1).
- Version 0.10.0 in `pyproject.toml`, `flotilla/__init__.py`, `.claude-plugin/plugin.json`.

## Review Focus

- **A command whose arguments carry quotes, spaces, `$(...)`, `;` or a leading `-`** (`rig run -- node -e
  'console.log("$HOME; x")'`). Expected: the machine runs exactly that argv; nothing in it is evaluated by a shell on
  the way. Pinned in Task 2 (`test_a_hostile_argv_arrives_as_written`) and Task 5
  (`test_rig_run_runs_the_argv_as_written`).
- **An artifact archive that tries to escape** (`../x`, `/etc/x`, a symlink, a hard link, a device, a member past
  the cap). Expected: refused before anything in the tree changes. Pinned in Task 3
  (`test_get_refuses_and_leaves_the_tree_untouched`).
- **The connection drops mid-run.** Expected: exit 75, verdict `lost`, the machine back to `ready` (not left
  `busy`), no artifact half-merged. Pinned in Task 5 (`test_a_dropped_connection_is_lost_not_red`).
- **Two runs for one machine.** Expected: the second waits and starts after the first ends; a waiting run whose
  process died never blocks the queue. Pinned in Task 1 (`test_a_dead_waiting_run_does_not_hold_the_line`) and
  Task 5 (`test_a_second_run_waits_for_the_first`).
- **A run past its ceiling.** Expected: the remote process group is stopped, not left computing on a paid machine;
  verdict `ceiling`, exit 124. Pinned in Task 5 (`test_a_run_past_its_ceiling_stops_the_remote_group`).

### Task 2: The remote half - ssh argv and constant scripts

**Files:**
- Create: `flotilla/rig/remote.py`, `tests/rigssh.py`
- Test: `tests/test_rig_remote.py`

**Interfaces:**
- Produces (`remote.py`):
  - `PROGRAM = "ssh"` (seam), `BASE = "/work"`, `BEAT = "/root/flotilla-heartbeat"`
  - `address(text) -> tuple[str, int]` - `host:port` with host `[A-Za-z0-9.-]{1,253}` not starting with `-`, port
    1-65535; else `ValueError`. The address comes from the journal, which any shell may write.
  - `ssh_argv(address_text, key: Path, known_hosts: Path, remote_line: str) -> list[str]`
  - `line(script: str, *args: str) -> str` - `bash -c <quoted script> flotilla <quoted args...>`
  - scripts (constants): `CHECK`, `RECEIVE`, `SETUP`, `STAGE`, `PUT`, `RUN`, `PACK`, `DROP`, `TOUCH`, `STOP`
  - `paths(project, revision, run_id, setup_hash, base=BASE) -> RemotePaths(rev, run, setup, pgrp)`
- Produces (`tests/rigssh.py`): `machine(tmp_path, monkeypatch) -> Path` - installs an executable stand-in as
  `remote.PROGRAM` that drops ssh options, `os.setsid()`s (like sshd), and runs the remote line with `bash -c`; sets
  `remote.BASE` and `remote.BEAT` under `tmp_path / "box"`. Returns the box root. `drop_after(n)` makes the stand-in
  exit 255 after n bytes of output (for `lost`).

```python
# flotilla/rig/remote.py (the core; scripts below)
import re
import shlex
from dataclasses import dataclass
from pathlib import Path

PROGRAM = "ssh"
BASE = "/work"
BEAT = "/root/flotilla-heartbeat"
_HOST = re.compile(r"[A-Za-z0-9][A-Za-z0-9.-]{0,252}")


def address(text: str) -> tuple[str, int]:
    host, _, port = (text or "").rpartition(":")
    if not _HOST.fullmatch(host) or not port.isdigit() or not 0 < int(port) < 65536:
        raise ValueError(f"not an ssh address: {text!r}")
    return host, int(port)


def ssh_argv(address_text: str, key: Path, known_hosts: Path, remote_line: str) -> list[str]:
    host, port = address(address_text)
    return [PROGRAM, "-i", str(key), "-o", "IdentitiesOnly=yes", "-o", "BatchMode=yes",
            "-o", "StrictHostKeyChecking=accept-new", "-o", f"UserKnownHostsFile={known_hosts}",
            "-o", "ServerAliveInterval=15", "-o", "ServerAliveCountMax=4", "-o", "ConnectTimeout=20",
            "-p", str(port), f"root@{host}", remote_line]


def line(script: str, *args: str) -> str:
    return " ".join(["bash", "-c", shlex.quote(script), "flotilla", *(shlex.quote(str(a)) for a in args)])
```

Scripts (each takes only positional arguments):
- `CHECK` ($1 rev dir): prints `present` if `$1/.flotilla-complete` exists, else `absent`.
- `RECEIVE` ($1 rev dir): untar stdin into `$1.incoming.$$`, touch `.flotilla-complete` inside, replace `$1`.
- `SETUP` ($1 rev, $2 setup dir, $3 command): if `$2/.flotilla-done` is missing: `rm -rf "$2/tree"`, copy `$1`
  into `$2/tree` (`cp -a "$1/." "$2/tree/"`), list top-level entries, run `bash -c "$3"` in `$2/tree`, write the new
  top-level entries (NUL-separated) to `$2/.flotilla-kept`, touch `$2/.flotilla-done`. Then, for each kept name
  missing in `$1`, `ln -s "$2/tree/<name>" "$1/<name>"`. Exit with the setup's code when it fails, leaving no
  `.flotilla-done`.
- `STAGE` ($1 rev, $2 run dir): `rm -rf "$2"; mkdir -p "$2"; cp -a "$1/." "$2/"`.
- `PUT` ($1 run dir): `tar -x --no-same-owner -C "$1" -f -`.
- `RUN` ($1 run dir, $2 pgrp file, then NAME=VALUE..., then the command argv): `cd "$1"`, write this shell's
  process group (`cut -d' ' -f5 /proc/$$/stat`) to `$2`, `shift 2`, `exec env -- "$@"`.
- `PACK` ($1 run dir, then paths): tar to stdout the paths that exist (`tar -c -f - -- ./p ...`); nothing when none.
- `DROP` ($1 run dir, $2 pgrp file): `rm -rf -- "$1" "$2"`.
- `TOUCH` ($1 file): `touch "$1"`.
- `STOP` ($1 pgrp file): `kill -TERM -- "-$(cat "$1")"`, wait up to 5 s, then `kill -KILL`; always exit 0.

def tar_bytes(files):
    import io, tarfile
    out = io.BytesIO()
    with tarfile.open(fileobj=out, mode="w") as t:
        for name, text in files.items():
            info = tarfile.TarInfo(name)
            info.size = len(text.encode())
            t.addfile(info, io.BytesIO(text.encode()))
    return out.getvalue()

### Task 3: Transfer - the tree's gate, `--put`, `--get`

**Files:**
- Create: `flotilla/rig/transfer.py`
- Test: `tests/test_rig_transfer.py`

**Interfaces:**
- Produces:
  - `class Refused(ValueError)`
  - `relative(root: Path, text: str) -> str` - a path inside the tree, normalised, POSIX; refuses absolute, `..`
    leaving the tree, empty
  - `unsent(root) -> list[str]` - tracked files with uncommitted changes (`git status --porcelain=v1 -z
    --untracked-files=no`, both columns), relative
  - `gate(root, puts: list[str]) -> str` - the committed HEAD sha; `Refused` when HEAD is missing or a changed
    tracked file is not among `puts`
  - `put_tar(root, puts) -> bytes` - a tar of regular files and directories (walked, never followed); refuses
    `.env*`, `*.pem`, `id_*`, `credentials*` (any path component, case-insensitive), symlinks, anything outside
  - `unpack(root, data: bytes | BinaryIO, wanted: list[str], *, cap=500 * 2**20) -> list[str]` - checks every member
    first (regular file or directory only; name relative, inside one of `wanted`; sum of sizes within `cap`),
    extracts into `root/.flotilla-get-<random>`, then replaces each wanted path that arrived (old moved aside, new
    renamed in, old removed), returns the paths placed. Any refusal raises before the tree changes.
  - `lock_hash(root, revision, command) -> str` - sha256 over the command and the lock files at that revision
    (`git show <rev>:<name>` for `LOCKS`), 16 hex chars; `""` when the command is empty
  - `LOCKS = ("package-lock.json", "npm-shrinkwrap.json", "yarn.lock", "pnpm-lock.yaml", "uv.lock", "poetry.lock",
    "Pipfile.lock", "requirements.txt", "Cargo.lock", "go.sum", "Gemfile.lock")`

import io
import tarfile

import pytest

from flotilla.rig import transfer


def tar_of(members):
    """members: (name, kind, payload) with kind in file/dir/symlink/hardlink/fifo."""
    out = io.BytesIO()
    with tarfile.open(fileobj=out, mode="w") as t:
        for name, kind, payload in members:
            info = tarfile.TarInfo(name)
            info.type = {"file": tarfile.REGTYPE, "dir": tarfile.DIRTYPE, "symlink": tarfile.SYMTYPE,
                         "hardlink": tarfile.LNKTYPE, "fifo": tarfile.FIFOTYPE}[kind]
            if kind in ("symlink", "hardlink"):
                info.linkname = payload
                t.addfile(info)
            elif kind == "file":
                info.size = len(payload)
                t.addfile(info, io.BytesIO(payload))
            else:
                t.addfile(info)
    return out.getvalue()

CLI (`flotilla rig run`): `--put PATH` (repeat), `--get PATH` (repeat), `--env NAME=VALUE` (repeat), `--wait S`
(default 900), `--root .`, `--as NAME`, `--why TEXT` (default "a heavy run"), then `--` and the command

Test helpers in `tests/test_rig_run.py`: `rig_run(world, tree, *argv) -> (code, out)` calls

`close_all(world)` closes the open session as `rig close` does; `set_ceiling(tree, s)` commits `[lane]
max_run_seconds`; `no_process_left(box)` reads the pgrp file `DROP` left (the test keeps a copy before DROP via a

more than one `lease_until` written for the machine; `drop_after(monkeypatch, n)` from `rigssh`.

Exit codes: the remote command's; `75` lost; `124` ceiling; `2` refused (gate, no session, image, budget, setup
failed); `3` no machine within `--wait` (the run is finished `waited`, the queue moves on).

Order of `run.main`:
1. **Gate, nothing spent yet:** rig on; `--env` names match `[A-Za-z_][A-Za-z0-9_]*` and contain none of `KEY`,
   `TOKEN`, `SECRET`, `PASSWORD` (case-insensitive); `--put`/`--get` through `transfer.relative`; `transfer.gate`
   -> revision; an open session (else the same refusal-with-request as `rig up`); the session's projected spend under
   `DRAIN_AT` of its budget.
2. **Queue:** `queue_run(...)` with this process's pid and start mark. From here on every exit path calls
   `finish_run` (a `try/finally`), so the queue never keeps a run this process left.
3. **Machine:** until `--wait` passes: if this run is the head and a `ready` machine of the session exists ->
   `start_run`; else if it is the head and no machine of the session is `requested`/`provisioning`/`ready`/`busy`
   -> `raise_machine(..., wait=min(remaining, 100))` (2 -> finish `refused`, exit 2); else sleep `POLL`. A `busy`
   machine means waiting: one run per machine.
4. **Renewal starts** (a daemon thread): at once and every `RENEW` seconds, `rig.renew([machine])` and
   `TOUCH BEAT` over ssh (timeout 30 s; a failure prints a note, never ends the run). Stopped in the `finally`.
5. **Tree:** `CHECK`; when `absent`, `git archive --format=tar <revision>` piped into `RECEIVE` (two processes, the
   archive's stdout into ssh's stdin; both exit codes checked). Then, when `profile.setup`: `SETUP` with the setup
   dir `remote.paths(...).setup` and the command; a failing setup finishes the run `setup failed`, exit 2, printing
   the setup's last lines.
6. **Stage:** `STAGE` rev -> run dir; `--put` tar into `PUT` when any.
7. **Command:** `EXECUTE(ssh_argv(... line(RUN, run_dir, pgrp, *env_pairs, *command)), ceiling=ceiling_for(...))`.
   - `result.exit == 255` -> verdict `lost`, exit 75; the machine's reason notes `run j<N> lost its connection`.
     *Planner's ruling:* the spec says the machine "is marked suspect"; the machine's `suspect` field already belongs
     to the reaper's two-pass listing rule, and writing it here would make one pass count as two. The run writes the
     reason and frees the machine; whether the box still lives is the reaper's listing check, as for every machine.
   - `result.at_ceiling` -> `STOP pgrp` over ssh, verdict `ceiling`, exit 124.
   - a local `KeyboardInterrupt` -> `STOP`, verdict `stopped`, re-raise after the record.
   - else verdict `green`/`red` with the remote exit code.
8. **Artifacts (also after red and ceiling, not after lost):** `PACK run_dir *gets` streamed into a temporary file
   locally (ssh stdout -> file, size checked as it arrives against the cap), then `transfer.unpack`. A refusal
   prints why and leaves the tree; the run's verdict stands.
9. **Cleanup:** `DROP` (best effort). `finish_run(verdict, exit, seconds, cost=hourly * seconds / 3600)`. Print one
   last line: `rig run j<N>: <verdict> in <s> s on m<M> (<cost> $)`.
