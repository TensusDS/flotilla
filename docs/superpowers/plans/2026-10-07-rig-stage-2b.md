# Rig stage 2b (0.10.0) - `rig run` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A seat runs a command on a rented machine - `flotilla rig run [--put P]... [--get P]... [--env N=V]... --
COMMAND` - and gets its output, its exit code and its artifacts back, inside the person's open session; several
runs share one machine; every run is measured on the machine so 0.11.0 can pack by estimates.

**Architecture:** Three new modules under `flotilla/rig/`:
- `remote.py` - the ssh command line (reads no config of the person's) and the constant shell scripts the machine
  runs; what varies travels as quoted positional arguments, never spliced into a script.
- `transfer.py` - the gate on the tree, `--put` packing with its refusals, the checks on `--get`, the safe unpack.
- `run.py` - the run: gate, queue and room, machine, tree, setup, command, renewal, the end (green, red, ceiling,
  cut, lost, stopped), artifacts, measurements, record.

The journal gains run records (`j1`, `j2`, ...); a machine is `busy` while any run is on it. Each run executes in its
own copy of the revision (`/work/<project>/runs/<run id>`) with its own setup (shared download caches in
`/work/cache`), its processes tagged `FLOTILLA_RUN=<run id>`. Tests never call real ssh: a stand-in `ssh` forks a
child that starts its own session with a clean environment and runs the remote line in bash, the way sshd does, and
exits 255 on SIGTERM leaving the child alive, the way the OpenSSH client does.

**Tech Stack:** Python 3.11+ stdlib only, bash and GNU coreutils/tar on the machine, OpenSSH client, pytest.

**Spec:** `docs/specs/2026-10-06-rig-design.md` - section 7 (revised 2026-10-07) is binding; sections 4-6 and 12
("Live check 1") constrain it; section 11 stages 2b/2c bound this release.

## Global Constraints

- Python stdlib only; `requires-python >= 3.11`; Linux and macOS field machines; English only
  (`tools/check_no_cyrillic.py`); lines at most 120 characters.
- No real network, crontab, ssh or ssh-keygen in tests; `pyproject.toml` sets `-q` (no second `-q`).
- Spending only inside a session the person opened; a run never opens one.
- ssh: `-F /dev/null`, no agent or X forwarding, no multiplexing, no `SendEnv`; stdin closed for calls that send no
  data (spec section 7, "Environment").
- `--env` names: `[A-Za-z_][A-Za-z0-9_]*`, none containing `KEY`, `TOKEN`, `SECRET`, `PASSWORD` (case-insensitive).
- `--put` refuses `.env*`, `*.pem`, `id_*`, `credentials*`, `.npmrc`, `.netrc`, `.pypirc`, any `.git` component,
  anything outside the tree, real paths under the state dir, `~/.ssh`, `~/.config/flotilla`, `~/.claude`, symlinks.
- `--get` refuses the root, any `.git` or `.claude` component, paths tracked at HEAD, paths under a local symlink;
  members: regular files and directories only, inside the wanted paths, total <= 500 MB; temp dir, then move.
- `--root` is the same repository as the caller's working directory.
- The ceiling is `[rig] max_run_seconds`, default 1800 (the person's decision, 2026-10-07).
- Room in 0.10.0: fewer than 2 runs on the machine, or free memory and free GPU memory on the machine above their
  margins; arrival order per session. Packing by estimates is 0.11.0, not here.
- Lease and heartbeat (`touch /root/flotilla-heartbeat`) renewed every 5 minutes by the run.
- Version 0.10.0 in `pyproject.toml`, `flotilla/__init__.py`, `.claude-plugin/plugin.json`.

**Interfaces:**
- Produces:
  - `WAITING, RUNNING, DONE = "waiting", "running", "done"`; `RUN_STATES`; `FLOOR = 2`
  - `@dataclass Run: id, session="", machine="", who="", project="", revision="", program="", ladder: tuple = (),
    state="", verdict="", exit: int | None = None, seconds: float | None = None, cost: float | None = None,
    peak_mb: int | None = None, cores: float | None = None, gpu_mb: int | None = None, pid: int | None = None,
    mark="", since="", reason=""`

  - `Rig.runs() -> dict[str, Run]`
  - `Rig.queue_run(session_id, *, who, project, revision, program, ladder, pid, mark) -> Run`
  - `Rig.head(session_id, alive) -> Run | None` - the oldest waiting run of that session whose `(pid, mark)` lives
  - `Rig.on(machine_id) -> list[Run]` - the running runs on a machine
  - `Rig.start_run(run_id, machine_id, *, alive, roomy: bool) -> Run | None` - one transaction: the run waits and is
    its session's head; the machine is `ready` or `busy` and in the run's session; fewer than `FLOOR` runs are on it,
    or `roomy` (the caller read the machine just now). Writes run -> `running` with `machine`; a `ready` machine ->
    `busy` (`idle_since=""`). Otherwise `None`, nothing written.
  - `Rig.finish_run(run_id, verdict, *, exit=None, seconds=None, cost=None, reason="", **measured) -> Run` - run ->
    `done`; when no other run is `running` on its machine and the machine is `busy`, machine -> `ready`.

```python
import re
import shlex
from dataclasses import dataclass
from pathlib import Path

PROGRAM = "ssh"
BASE = "/work"
BEAT = "/root/flotilla-heartbeat"
_HOST = re.compile(r"[A-Za-z0-9][A-Za-z0-9.-]{0,252}")
#: The person's ssh config never applies: a `ForwardAgent yes` there would hand their agent to a stranger's host.
OPTIONS = ("-F", "/dev/null", "-a", "-x", "-T", "-o", "IdentitiesOnly=yes", "-o", "BatchMode=yes",
           "-o", "StrictHostKeyChecking=accept-new", "-o", "ClearAllForwardings=yes", "-o", "ControlMaster=no",
           "-o", "ControlPath=none", "-o", "PermitLocalCommand=no", "-o", "UpdateHostKeys=no",
           "-o", "ServerAliveInterval=15", "-o", "ServerAliveCountMax=4", "-o", "ConnectTimeout=20")


def address(text: str) -> tuple[str, int]:
    host, _, port = (text or "").rpartition(":")
    if not _HOST.fullmatch(host) or not port.isdigit() or not 0 < int(port) < 65536:
        raise ValueError(f"not an ssh address: {text!r}")
    return host, int(port)


def ssh_argv(address_text: str, key: Path, known_hosts: Path, remote_line: str) -> list[str]:
    host, port = address(address_text)
    return [PROGRAM, *OPTIONS, "-i", str(key), "-o", f"UserKnownHostsFile={known_hosts}", "-p", str(port),
            f"root@{host}", remote_line]


def line(script: str, *args) -> str:
    return " ".join(["bash", "-c", shlex.quote(script), "flotilla", *(shlex.quote(str(a)) for a in args)])
```

Scripts - module constants, positional arguments only, `set -u` in each:
- `CHECK` ($1 rev dir): `present` when `$1/.flotilla-complete` exists, else `absent`; a second line `gnu-tar yes|no`.
- `RECEIVE` ($1 rev dir, $2 sha256, $3 size): stdin through `tee >(sha256sum > "$1.incoming.$$.sum")` and a byte
  count into `tar -x -C "$1.incoming.$$"`; only when both match: touch `.flotilla-complete` inside and move it to
  `$1`; else remove the incoming dir, print `incomplete`, exit 65.
- `READINGS` (no args): one line `mem_kb=<MemAvailable> mem_total_kb=<MemTotal> cpus=<nproc> gpu_free_mb=<sum or
  -1> gpu_total_mb=<sum or -1> disk_free_mb=<free MB of the dir passed as $1>` ($1 = `BASE`).
- `STAGE` ($1 rev, $2 run dir): `rm -rf "$2"; mkdir -p "$2"; cp -a "$1/." "$2/"; rm -f "$2/.flotilla-complete"`.
- `PUT` ($1 run dir, $2 sha256, $3 size): the stream check of `RECEIVE`, extracting into a temp dir then copying
  into `$1` only when it matched.
- `RUN` ($1 run dir, $2 status file, $3 run id, $4 cache root, $5 count of env pairs, then that many `NAME=VALUE`,
  then the command argv). Its first line is the marker comment `# flotilla-run`. `cd "$1"`; for each pair check the
  name against `^[A-Za-z_][A-Za-z0-9_]*$` and `export -- "$pair"`; `export FLOTILLA_RUN="$3"
  npm_config_cache="$4/npm" UV_CACHE_DIR="$4/uv" PIP_CACHE_DIR="$4/pip" YARN_CACHE_FOLDER="$4/yarn"`; write
  `pgrp=<field 5 of /proc/$$/stat> started=<epoch>` to `$2.running`; start a sampler in the background (every 2 s:
  the sum of `VmRSS` of every `/proc/<pid>` whose environ holds `FLOTILLA_RUN=$3`, the maximum kept; when
  `nvidia-smi` exists, the used GPU memory of those pids, the maximum kept); run the command (not `exec`); `wait`;
  stop the sampler; `cpu_s` from fields 16-17 (`cutime`, `cstime`) of `/proc/$$/stat` over `getconf CLK_TCK`; write
  `$2` atomically (`$2.tmp`, then `mv`): `exit=<code> seconds=<n> cpu_s=<n> peak_kb=<n> gpu_mb=<n>`; exit with the
  command's code.
- `STATUS` ($1 status file): the status line when `$1` exists; else `running pgrp=<n>` when `$1.running` exists and
  its group has a member; else `vanished`.
- `STOP` ($1 status file, $2 run id): TERM to the group named in `$1.running` (when present) and to every pid whose
  environ holds `FLOTILLA_RUN=$2`; up to 5 s for them to end; then KILL to whatever is left; prints `stopped <n>`;
  exits 0.
- `PACK` ($1 run dir, then paths): `tar -c -f - -- ./p ...` of those that exist; nothing when none.
- `DROP` ($1 run dir, $2 status file): `rm -rf -- "$1" "$2" "$2.running" "$2.tmp"`.
- `TOUCH` ($1 file): `touch -- "$1"`.
- `PRUNE` ($1 project dir, $2 revisions to keep): remove `runs/*` and status files not touched for a day; keep the
  newest `$2` revisions by mtime; print the free MB after.

CLI: `flotilla rig run [--put P]... [--get P]... [--env N=V]... [--wait S=900] [--root .] [--as NAME] [--why TEXT]
-- COMMAND` (`argparse.REMAINDER`, a leading `--` stripped as the lane does; refused when empty). `rig` stays out of
`OWN_SUBCOMMANDS` (`broker/decide.py`): it keeps the permission prompt.

Exit codes: the command's own; `75` cut or lost; `124` ceiling; `130` stopped by a signal; `2` refused (gate, no
session, image, budget, disk, setup failed); `3` no room within `--wait`. The last line printed always reads
`rig run j<N>: <verdict> (exit <code>) in <s> s on m<M>, <cost> $`, so a command's own 2/3/75/124 is told apart.

Order of `run.main`:
1. **Signals:** SIGTERM and SIGHUP become `SystemExit(130)` (as the lane's `_on_signals`), so the `finally` below
   always runs.
2. **Gate, nothing spent yet:** rig on; `--env` names; `transfer.same_repository(root, cwd)`; `--put` through
   `relative`; `--get` through `relative` and `check_gets`; `transfer.gate` -> revision; the profile; an open session
   (else the same refusal-with-request as `rig up`); the session's projected spend under `DRAIN_AT` of its budget.
3. **Queue:** `queue_run(...)` with this pid, its start mark, `program = basename(command[0])`, `ladder =
   signature.ladder(command, tree=str(root), project=key)`. Every path from here ends in `finish_run`.
4. **Room:** until `--wait` passes, when this run is its session's head:
   - a `ready` or `busy` machine of the session with fewer than `FLOOR` runs on it -> `start_run(..., roomy=False)`;
   - else such a machine whose `READ` (the `READINGS` script over ssh) shows `mem_kb / 1024 >= MARGIN_MB` and
     (`gpu_free_mb == -1` or `>= GPU_MARGIN_MB`) -> `start_run(..., roomy=True)`; the first readings of a machine
     write its shape (`note(cpus=, ram_mb=, gpu_total_mb=)`);
   - else, when the session has no machine `requested`/`provisioning`/`ready`/`busy` and the ceiling allows ->
     `raise_machine(..., wait=min(remaining, 100))` (2 -> finish `refused`, exit 2);
   - else sleep `POLL`.
   No room within `--wait` -> finish `waited`, exit 3.
5. **Renewal** (a daemon thread, stopped and joined in the `finally` before `finish_run`): at once and every `RENEW`
   seconds, `rig.renew([machine])` while this run is still `running` on it, and `TOUCH BEAT` over ssh (timeout 30 s;
   a failure prints a note). Known hosts for the machine: `<state>/rig/hosts/<machine id>`.
6. **Disk and tree:** `PRUNE` of the project dir keeping 5 revisions; under 2048 MB free after it -> finish
   `refused` ("the machine's disk is full"), exit 2. `CHECK`: GNU tar `no` -> finish `refused`; `absent` ->
   `git archive --format=tar <revision>` into a local temporary file, then `RECEIVE` with its sha256 and size.
7. **Stage:** `STAGE` rev -> run dir; `--put` tar into `PUT` with its sha256 and size.
8. **Setup:** when `profile.setup`: `EXECUTE` of `RUN` with the command `bash -c <setup>` (tagged, measured, under the
   ceiling's remainder); non-zero -> finish `setup failed`, exit 2.
9. **Command:** `EXECUTE(ssh_argv(... line(RUN, run_dir, status, run_id, cache_root, n, *env_pairs, *command)),
   ceiling=max_run_seconds - elapsed)`. Then, in this order:
   - `result.at_ceiling` -> `STOP`; verdict `ceiling`, exit 124;
   - `SystemExit` from a signal or `KeyboardInterrupt` -> `STOP`; verdict `stopped`, exit 130 (re-raised after the
     record);
   - `result.exit == 255` -> ask: `STATUS` over a fresh ssh every 10 s for up to `ASK_FOR` s:
     - a status line -> the command's real verdict from it;
     - `running` -> `STOP`, verdict `cut`, exit 75;
     - `vanished` -> verdict `cut`, exit 75;
     - stderr holds `REMOTE HOST IDENTIFICATION HAS CHANGED`, or no answer within `ASK_FOR` -> verdict `lost`, exit
       75, and the machine moves to `draining` with that reason (not handed to the next run);
   - else the status line gives `green` or `red` with the code.
10. **Artifacts (after green, red, ceiling, cut and stopped; not after lost):** `PACK run_dir *gets` with stdout into a
    local temporary file, its size checked as it arrives (past the cap + 1 MB the call is stopped);
    `transfer.unpack`. A refusal prints why; the verdict stands.
11. **Measurements and record:** from the status line `seconds`, `cpu_s` (-> `cores = cpu_s / seconds`),
    `peak_kb` (-> `peak_mb`), `gpu_mb`; `cost = hourly * busy_seconds / 3600`, `busy_seconds` from `start_run` to
    the end. `DROP`. `finish_run(...)`. The last line.

*Planner's ruling (cost on a shared machine):* a run's cost is the machine's price over the time it held a place on
it; two runs side by side add up to more than the machine cost. The session's spend stays the machine accounting
(section 5); a run's cost answers "what did this run hold", not "who pays which cent".

def order(world):
    lines = (world["state"] / "rig" / "rig.jsonl").read_text().splitlines()
    return [(r["kind"], r["id"], r["state"]) for r in map(json.loads, lines)]


def running(world):
    return sum(1 for r in journal(world).runs().values() if r.state == "running")


def wait_for(predicate, seconds=10.0):
    end = time.time() + seconds
    while time.time() < end:
        if predicate():
            return
        time.sleep(0.05)
    raise AssertionError("condition not met in time")
