# Rig stage 2a (0.9.0) - a machine made, watched and given back - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The person opens a rig session by their yes; any session raises one machine inside it with `rig up`; the
machine carries a watchdog; the reaper, the journal and the orchestrator's screen see every state; and live check 1
proves on real vast that a machine is destroyed and gone when our side dies - all before any run exists (0.10.0).

**Architecture:** Stage 1 (0.8.0) left the journal, the reaper, the launcher, the vast adapter's listing and destroy,
the person guard and `flotilla rig`. This plan adds: the final review's four minors; requests and a machine ceiling in
the journal; the adapter's offers, create, ssh key and start script (contract grown by one row field, `address`);
`rig open`/`close` (the person's moves) and `rig up` (any session, inside an open session); a `surface` module whose
items join the orchestrator's `watch` and session-start screen and whose lines join `flotilla fleet`; the orchestrator
post v15; and a live-check procedure run with the person's yes before the release is tagged.

**Tech Stack:** Python 3.11+ standard library only; pytest; `ssh-keygen` (OpenSSH) on the field machine.

**Spec:** `docs/specs/2026-10-06-rig-design.md` - sections 4, 5, 7, 11 (stage 2a) and 12.

## Global Constraints

- English only (`tools/check_no_cyrillic.py`); Python standard library only; no new dependency.
- vast's base URL is the constant `https://console.vast.ai`; the key goes only in `Authorization: Bearer`; offers
  search is `POST /api/v0/bundles/`, create is `PUT /api/v0/asks/<offer>/`, an instance's ssh key is
  `POST /api/v0/instances/<id>/ssh/`; a non-2xx answer, a timeout or an unparsable body is a failure.
- Offers: datacenter hosts only (`hosting_type` 1), verified, rentable and not rented, one GPU, reliability >= 0.98,
  price <= the person's `rig_max_hourly`, disk >= the profile's `disk_gb`; cheapest first. Filtered again locally:
  an offer the service returns outside the filter is dropped.
- Adapter rows carry exactly `instance`, `label`, `status`, `hourly`, `address`; offer rows exactly `offer`, `gpu`,
  `hourly`, `reliability`, `datacenter`. Nothing else of a service's answer leaves the adapter.
- `rig open`, `rig close`, `rig enable`, `rig disable` are the person's moves: refused to Claude's tool calls by the
  guard hook (including globbed words, `r?g`, `w?rk`), refused to a background session by `caller.person_refusal`.
- One session open at a time; hours <= `rig_max_hours`; budget > 0; live machines <= `rig_max_machines`, counted
  inside the journal's transaction. `rig open`/`close`/`up` refuse while the journal is damaged.
- The watchdog limit is `FLOTILLA_WATCHDOG_MINUTES`, 5 to 45, default 45; `rig up --watchdog-minutes` may only lower it.
- Every crontab edit happens under `<state>/rig/reap.lock`.
- Nothing in the suite spends money, opens a connection, runs `ssh-keygen`, or touches the person's crontab.
- Tests: `uv run --with pytest python -m pytest tests` (pyproject already passes `-q`; never add another, or the
  summary line is hidden); a verdict is read from the tail (`N passed`). `$SCRATCH` is the session's scratchpad.
- Live check 1 spends at most 0.50 $ by the person's yes (given 2026-10-07); it runs before the tag.

## Review Focus

- **Two seats call `rig up` at once with `rig_max_machines = 1`.** Expected: exactly one machine is requested; the
  other is refused by the journal's transaction. Pinned in Task 2 (`test_the_machine_ceiling_holds_inside_the_transaction`).
- **The create call fails after vast made the instance (timeout on the answer).** Expected: the machine is `failed`
  with no instance; the reaper turns it `gone`, then destroys the labelled instance as an orphan. Pinned in Task 6

```python
        return _fold(self.store.read(KEY).records)[2]

    def ask(self, who: str, why: str) -> Request:
        """A session wanted a machine and found no session open: the orchestrator relays it to the person."""
        with self.store.transaction(KEY) as tx:
            request_id = _next_id("r", _fold(tx.read().records)[2])
            self._append(tx, "request", request_id, ASKED, who=who, why=why)
            return _fold(tx.read().records)[2][request_id]

    def answer_requests(self, reason: str) -> list[Request]:
        with self.store.transaction(KEY) as tx:
            waiting = [item for item in _fold(tx.read().records)[2].values() if item.state == ASKED]
            for item in waiting:
                self._append(tx, "request", item.id, ANSWERED, reason=reason)
            found = _fold(tx.read().records)[2]
            return [found[item.id] for item in waiting]
```

```python
"""The rig's own ssh key (rig design, section 6): made once, with no passphrase because cron and background seats use
it, and refused when others may read it. Its public half is attached to each instance at create; the person's own
keys are never offered to a rented machine."""

from __future__ import annotations

import os
import stat
import subprocess
from pathlib import Path

NAME = "flotilla_rig_ed25519"


class KeyError_(RuntimeError):
    """The rig's ssh key cannot be made or used."""


def paths(home: Path | None = None) -> tuple[Path, Path]:
    private = Path(home or Path.home()) / ".ssh" / NAME
    return private, private.with_name(NAME + ".pub")


def ensure(home: Path | None = None, run=subprocess.run) -> str:
    private, public = paths(home)
    if not private.exists():
        private.parent.mkdir(mode=0o700, parents=True, exist_ok=True)
        try:
            done = run(["ssh-keygen", "-t", "ed25519", "-N", "", "-C", "flotilla rig", "-f", str(private), "-q"],
                       capture_output=True, text=True, timeout=60, check=False)
        except (OSError, subprocess.TimeoutExpired) as err:
            raise KeyError_(f"ssh-keygen could not be run: {err}") from None
        if done.returncode != 0:
            raise KeyError_(f"ssh-keygen failed: {(done.stderr or done.stdout or '').strip()[:200]}")
    info = os.lstat(private)
    if not stat.S_ISREG(info.st_mode) or stat.S_IMODE(info.st_mode) & 0o077:
        raise KeyError_(f"{private} is not a private regular file; `chmod 600 {private}`")
    try:
        text = public.read_text(encoding="utf-8").strip()
    except OSError as err:
        raise KeyError_(f"{public} cannot be read: {err}") from None
    if not text.startswith("ssh-ed25519 "):
        raise KeyError_(f"{public} is not an ed25519 public key")
    return text
```

```python
"""The project profile's `[rig]` section (rig design, section 7): the image, the GPUs and the disk a project's heavy
runs need. A value that does not look like one falls back to its default, and the reason is kept to be shown: a
profile is written by sessions too, and an image name reaches the provider's create call."""

from __future__ import annotations

import re
from dataclasses import dataclass, field

DEFAULT_IMAGE = "mcr.microsoft.com/playwright:v1.48.0-jammy"
DEFAULT_DISK = 30
_IMAGE = re.compile(r"[a-z0-9][a-z0-9./_:@-]{0,200}")
_GPU = re.compile(r"[A-Za-z0-9 _.-]{1,40}")


@dataclass(frozen=True)
class RigProfile:
    image: str
    gpus: tuple
    disk_gb: int
    problems: tuple = field(default=(), compare=False)


def read(data: dict) -> RigProfile:
    section = data.get("rig") if isinstance(data, dict) else None
    section = section if isinstance(section, dict) else {}
    problems = []
    image = section.get("image", DEFAULT_IMAGE)
    if not isinstance(image, str) or not _IMAGE.fullmatch(image):
        problems.append(f"[rig] image {image!r} is not an image name; using {DEFAULT_IMAGE}")
        image = DEFAULT_IMAGE
    gpus = section.get("gpu", [])
    gpus = [gpus] if isinstance(gpus, str) else gpus if isinstance(gpus, list) else []
    kept = tuple(name for name in gpus if isinstance(name, str) and _GPU.fullmatch(name))
    if len(kept) != len(gpus):
        problems.append("[rig] gpu holds names that are not GPU names; they are left out")
    disk = section.get("disk_gb", DEFAULT_DISK)
    if isinstance(disk, bool) or not isinstance(disk, int) or not 10 <= disk <= 500:
        problems.append(f"[rig] disk_gb {disk!r} is not 10-500; using {DEFAULT_DISK}")
        disk = DEFAULT_DISK
    return RigProfile(image, kept, disk, tuple(problems))
```

```python
def _locked(state: Path, fn, wait: float = 30.0):
    """Run fn holding the reaper's lock, so no crontab edit or ceiling count races a pass (rig design, section 5)."""
    folder = state / "rig"
    folder.mkdir(parents=True, exist_ok=True)
    deadline = time.monotonic() + wait
    with open(folder / "reap.lock", "a") as lock:
        while True:
            try:
                fcntl.flock(lock, fcntl.LOCK_EX | fcntl.LOCK_NB)
                break
            except BlockingIOError:
                if time.monotonic() >= deadline:
                    raise TimeoutError("the reaper's lock stayed held; try again in a minute") from None
                time.sleep(0.5)
        return fn()


def _number(text: str, *, what: str) -> float:
    try:
        value = float(text)
    except ValueError:
        raise ValueError(f"{what} is not a number: {text!r}") from None
    if not math.isfinite(value) or value <= 0:
        raise ValueError(f"{what} must be more than 0")
    return value
```

```python
"""What the orchestrator is told about rented machines, and what `flotilla fleet` lists (rig design, section 3).

Items join the orchestrator's `watch` and session-start screen beside the fleet's own; each names what is wrong and
what to do. A request a seat made with no session open carries the very line the person pastes - the orchestrator
relays it, the person's yes stays the person's.
"""

from __future__ import annotations

import datetime as dt
from pathlib import Path

from flotilla.core.storage import LocalLogStore, StorageCorrupt
from flotilla.rig import health
from flotilla.rig import journal as j
from flotilla.rig import settings as rs
from flotilla.watch.whose import Item

KIND = "rig"
SLOW = dt.timedelta(minutes=10)
ENDING = dt.timedelta(minutes=15)
WARN_AT = 0.8


def _when(text: str):
    return dt.datetime.fromisoformat(text) if text else None


def _hhmm(moment: dt.datetime) -> str:
    return moment.astimezone().strftime("%H:%M")


def _item(text: str, since: str, who: str) -> Item:
    return Item(kind=KIND, branch="", text=f"rig: {text}", since=since, who=who)


def items(state: Path, now: dt.datetime) -> list[Item]:
    on = rs.settings(state).on
    rig = j.Rig(LocalLogStore(state / "rig"), clock=lambda: now)
    try:
        machines, sessions, requests = rig.machines(), rig.sessions(), rig.requests()
    except StorageCorrupt as err:
        return [_item(f"the rig journal is damaged ({err}); `flotilla rig reap` destroys this machine's labelled "
                      "instances", "", "rig:journal")]
    live = [m for m in machines.values() if m.state in j.LIVE]
    if not on and not live and not requests:
        return []
    found = []
    for machine in live:
        if machine.state == j.STUCK:
            found.append(_item(f"machine {machine.id} STUCK ({machine.reason or 'still listed'}) - instance "
                               f"{machine.instance} may still cost money; check the service's console", machine.created,
                               f"rig:stuck:{machine.id}"))
        created = _when(machine.created)
        if machine.state == j.PROVISIONING and created and now - created > SLOW:
            minutes = int((now - created).total_seconds() // 60)
            found.append(_item(f"machine {machine.id} provisioning for {minutes} min (instance {machine.instance})",
                               machine.created, f"rig:slow:{machine.id}"))
    if live:
        last = health.last_reap(state)
        ok, note = health.last_outcome(state)
        if last is None or now - last > health.SILENT_AFTER:
            found.append(_item("the reaper is silent while a machine lives - is cron running? `flotilla rig reap` now",
                               "", "rig:silent"))
        elif not ok:
            found.append(_item(f"the last reaper pass failed: {note}", "", "rig:failed"))
    open_ = [s for s in sessions.values() if s.state == j.OPEN]
    for session in open_:
        spent = rig.spent(session.id, now)
        if session.budget and spent >= WARN_AT * session.budget:
            found.append(_item(f"session {session.id} has spent at least {spent:.2f} $ of its budget "
                               f"{session.budget:.2f} $", session.opened, f"rig:budget:{session.id}"))
        until = _when(session.until)
        busy = [m for m in live if m.session == session.id and m.state == j.BUSY]
        if until and busy and now < until <= now + ENDING:
            found.append(_item(f"session {session.id} ends at {_hhmm(until)} with machine(s) still busy "
                               f"({', '.join(m.id for m in busy)})", session.opened, f"rig:ending:{session.id}"))
    if not open_:
        for request in (r for r in requests.values() if r.state == j.ASKED):
            found.append(_item(f"{request.who} asks for a machine ({request.why}); no session is open - ask the "
                               f'person to paste: ! flotilla rig open --hours 2 --budget 1 --why "{request.why}"',
                               request.since, f"rig:request:{request.id}"))
    return found


def lines(state: Path, now: dt.datetime) -> list[str]:
    rig = j.Rig(LocalLogStore(state / "rig"), clock=lambda: now)
    try:
        machines, sessions = rig.machines(), rig.sessions()
    except StorageCorrupt as err:
        return [f"rig: the journal is damaged ({err})"]
    live = [m for m in machines.values() if m.state in j.LIVE]
    shown = [s for s in sessions.values() if s.state in (j.OPEN, j.CLOSING)]
    if not rs.settings(state).on and not live and not shown:
        return []
    found = []
    for session in shown:
        budget = f"{session.budget:.2f}" if session.budget is not None else "?"
        until = _when(session.until)
        found.append(f"rig: session {session.id} {session.state} ({session.why}) until "
                     f"{_hhmm(until) if until else '?'}, spent at least {rig.spent(session.id, now):.2f} of {budget} $")
    if not shown:
        found.append("rig: no session open")
    for machine in live:
        price = f"{machine.hourly:.3f} $/h" if machine.hourly is not None else "price unknown"
        found.append(f"  machine {machine.id} {machine.state}: {machine.gpu or 'gpu ?'}, {price}"
                     f"{', ' + machine.address if machine.address else ''}"
                     f"{' (' + machine.reason + ')' if machine.reason else ''}")
    return found
```
